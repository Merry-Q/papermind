## 首次浏览器运行中发现并修复

跨文档后侧栏的桌面打开状态会延续到窄屏，导致测试中一次点击将已打开面板关闭。已将新文档的移动面板状态重置，并使桌面“打开侧栏”不污染移动状态；随后浏览器测试通过。

原文视图切换的阅读位置恢复补充了显式保存与恢复，并增加对应端到端断言；最终构建上该断言已通过。桌面无作用的“打开阅读侧栏”按钮已限制到侧栏收起的窄屏布局，目录中容易误解为已读的未访问勾号和重复分类标签已移除。
