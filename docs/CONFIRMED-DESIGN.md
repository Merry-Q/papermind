# PaperMind 已确认的产品决策

记录日期：2026-10-24。来自用户在 grill-me 对话中的明确选择；未修改产品代码。

1. 单次学习的效果目标：用户能独立解释关键方法为什么成立，及其基础概念与假设。
2. 不提供面向用户的理解检查、测试或掌握评分。用户自行控制讲解深度。
3. 围绕当前论文补充理解所需知识，深入学习作为可选分支，并能返回原文。知识补充可能是概念、推导、背景、对比或适用条件，不统称为“基础”。
4. 原文外的关键定义、公式和适用条件需要可追溯外部依据。区分论文原文、外部知识和教学加工。
5. 正文保留中性的概念解释入口，供查阅定义、符号及相关解释。用户实际卡点主要依据 Copilot 中的提问、追问和反馈识别，不按预设人群或经验断言用户缺少某种知识；歧义时可以简短澄清，不作理解测试。
6. 用户主动加入个人概念库，作为自报已理解及以后省略重复讲解的信号。未加入则跨论文继续提供解释。
7. 概念库按讲解层级复用；新论文的新增推导、用法、特殊定义与条件继续解释。
8. 上传后的默认入口是论文全貌，允许直接设置阅读目标或进入 Copilot。
9. Copilot 的解释或演示经用户选择后加入对应页面节点，保留来源、可以撤回。
10. 加入当前页面与加入个人概念库是两项独立动作。
11. 默认沿 AI 重组的交互讲解阅读，允许切回原始 PDF 核对。
12. 首轮生成结束后必须有覆盖全篇核心论证、可以从头读到尾的完整交互讲解；不能依赖追问拼出主线。
13. 讲解以论文内容为主，不预先为整个读者划定“小白／中阶／高阶”等级。
14. 核心公式、变量含义、关键推理和成立条件进入主线；详细推导默认折叠，允许逐步展开。
15. 优先提供机制探索交互，形式随论文内容选择，不为凑数量硬加滑块或动画。

16. 知识递归在右侧栏展开，论文讲解主线保持位置稳定；保留展开路径，允许返回上层。
17. 右栏从知识视图切换到 Copilot 时，携带当前知识点和论文上下文；返回后恢复知识层级与阅读位置。
18. 首轮生成过程中，已完成并检查过的部分可先读；显示全篇目录及生成状态；全部就绪后才标记“完整讲解已生成”。已读内容修订时提示用户。
19. 对话驱动的知识补充与正文概念查阅并存。用户可以把有用的补充加入页面，或将相应知识层级加入个人概念库，两个动作独立。
20. 对话形成的解释需求和偏好可跨论文复用，自动沉淀并给可撤销提示；用户可以查看对话依据、修改和删除。一次提问不能直接变成永久的能力判断；这些记忆不自动改变概念库状态。
21. 一篇论文共用一条连续对话，每条提问保存当时的阅读位置；切换节点更新当前上下文，允许跨章节讨论。
22. 关键公式或图表无法可靠解析、导致核心论证缺口时，保留可读草稿，在缺口处说明原因并提供原文入口。整篇保持“未完整”，支持补充材料后继续生成，不把缺失推断填充为已经核对的论文事实。
23. 首版优先应用内阅读，打通交互讲解、知识补充、对话和概念库；独立交互页面导出随后考虑。
24. 首版支持选中公式、图表或 PDF 区域提问，Copilot 获取所选内容和相关上下文；识别不清时明确说明。
25. Copilot 可以按用户要求调整已有交互演示的参数或步骤，同步解释变化，允许恢复先前状态；新增讲解加入正文仍由用户选择。
26. 当前论文的对话允许用户明确附加其他论文作参考，比较具体方法、假设或结论，并分别引用各篇论文。
27. 缺少完整实验参数或代码时，允许使用自建简化数据生成教学交互模型。明确标注教学用途、简化内容及关键成立条件，不能将演示数值作为论文结果。
28. 首轮聚焦忠实讲解，外部资料用于补充理解；用户要求评价可靠性、反例或争议时，再展开外部文献评议。原文明示的假设、证据与局限正常进入讲解。
29. 首版通过 Copilot 修改讲解：用户提出调整要求，预览后应用到页面，保留来源并支持撤回；暂不提供直接编辑正文。

主要阅读流程与上述能力边界已经确认。具体工程方案、首版容量与性能目标、验收样本与检查阈值尚未确定。整合方案见同目录 design-synthesis.md；其中验收细则属于待验证建议，不自动成为用户已确认决策。草图采用虚构的教学示例，不构成真实论文分析或已实现产品；其中仍有旧的“基础”标签，需在下一轮更新时统一为中性的概念查阅和对话驱动的知识补充。
