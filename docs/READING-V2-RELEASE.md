# V2 已知问题修复与默认页发布

2026-10-25（北京时间）。本地服务已更新，默认入口为 http://127.0.0.1:8000/ 。

## 当前发布范围

- Attention 已发布为默认交互讲解；直接打开文档或在文档选择器切换到它即可，不需要 readingV2 预览参数。首次进入且没有阅读记录时，首页选择这份已发布材料。
- 原始 PDF、右侧 Copilot、知识补充、个人概念库保持原有流程。新版工具栏随阅读固定，支持恢复原讲解；刷新仍保留该选择，并可再次打开新版。
- RAG、5G 定位的修订版本保留为待核验草稿；定点计算和宿主检查通过，但全篇事实与视觉验收仍待完成，未设为默认。
- 首轮 8 篇测试没有全部完成。Shannon 和歌词论文任务中断、保留缓存，其余4篇未启动。CNNIC 未测。本次按用户新要求转入修复和默认页发布。

## 已修复

| 问题 | 修复与证据 |
|---|---|
| 通用提示词带 Attention 的专用表号、维度和固定章节要求 | 去掉通用编写指令中的 Table2/3/4、dk=3 等限制；按材料自身论证选择呈现。显式 Attention 验收接口仍独立保留。 |
| 章节有内容却缺少目录锚点 | 对唯一且有实质正文的 data-node 区段加真实语义容器，保留作者原选择器；无内容、归属不明的章节仍会被校验拦截。 |
| 各章复用 node-output、analysis-text 等 ID | 为私有 ID 及其 HTML/CSS/JS 引用统一加章节前缀；查询与非生命周期 DOM 事件限定在本章，键盘操作不再推动其他章节。 |
| 合法代码、SVG 定义被阻断 | 支持 code/pre、pattern、渐变与 stop；同时核验属性和 CSS 中的 url，只允许本地片段引用。资源外联、宿主访问与沙箱边界继续受限。 |
| 作者拿不到规划引用页和其他相关表格 | 结合节点与计划引用选原文；证据章节获得已抽取表格页，运行时提供完整只读表格账本。 |
| 5G 矩阵公式和列数不一致 | 按原 PDF 第4页式(7)修正乘法；qaz=qel=q 时列数为 q⁴，元素数为 Nt·Mt·q⁴，存储字节单独标注教学假设。 |
| q=18 被表述为所有设备的内存阈值 | 回查第7页：保留“论文模拟设置下超过18不实用”的原文限定，去掉普适溢出结论；四次多项式不再称为指数增长。 |
| 预设搜索轨迹和随机收敛曲线容易冒充真实实验 | 搜索示例按邻域规则实际重算并声明简化；移除随机结果曲线，改用真实耗时、运算量和五种参数的 RMSE。 |
| 5G 运行报 h 未定义、角度列 OCR 错字和手机溢出 | 修正画布局部高度、按原页校正 az/el 表头，调整窄屏布局与遮罩；正文与原始业务记录不变。 |
| RAG 控件只反馈状态、跨任务平均分误导比较 | K 立即改变文档图形，步骤改变信息流；消融只展示同一任务真实行，FEVER 说明合并单元格及两种变体等价；差值使用百分点。 |
| 同一数学正文在每次打开/PDF返回时重启排版进程 | 按正文缓存 MathML 结果，保持输出一致；本次服务内热打开接口约62–78毫秒。这是打开性能，不是大模型生成耗时。 |
| 默认版查询、回退与 PDF 返回存在时序问题 | 发布指针与草稿隔离；过期结果不覆盖用户选择；等页面高度与阅读位置恢复后开放工具栏，固定工具栏并补偿目录定位高度。 |

RAG 与 5G 的修订在克隆版本内完成，首次失败产物保留。原文可能缺少某些实验或存在符号歧义，不能为通过模型审阅补造证据；原始审阅意见与工程判定见 review-dispositions.json。
